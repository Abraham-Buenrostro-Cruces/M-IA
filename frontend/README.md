# Frontend — PWA de RutaAccesible

React + TypeScript + Vite, PWA con `vite-plugin-pwa`. Comandos en el `CLAUDE.md` de la raíz.

- `src/paginas/`: una página por ruta de React Router.
- `src/componentes/`: componentes compartidos (`Plantilla` maneja el salto al contenido y el foco al navegar).
- `src/pruebas/`: configuración de Vitest y ayuda de axe-core.
- `public/icono-*.png`: íconos **provisionales**.
